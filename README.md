# 🐾 わんおーわん

ワンちゃんがファシリテーターとして会話を進める、ブラウザー完結型の1on1 Webアプリです。

## 起動方法

依存ライブラリやビルドは不要です。`index.html` をブラウザーで開くと利用できます。

ローカルサーバーを使う場合：

```bash
python3 -m http.server 8000
```

その後、ブラウザーで `http://localhost:8000` を開いてください。

## 主な機能

- トップ → 名前入力 → 気分チェック → 6つの質問 → 振り返り → 履歴の一連の操作
- 入力途中の内容をブラウザーの `localStorage` に自動保存
- 1on1記録の保存・一覧・詳細表示・削除
- PC／スマートフォン対応のレスポンシブデザイン
- 追加パッケージ不要のHTML/CSS/JavaScript構成

## データについて

入力内容は現在のブラウザー内にのみ保存され、外部へ送信されません。ブラウザーのサイトデータを削除すると記録も削除されます。
